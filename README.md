# Evidence-to-Action: Reducing Admin Burden with Practical AI

A public-good research project from **Context Switch**, the build-house layer inside [markhay.net](https://markhay.net/context-switch).

This repository exists to produce free, no-paywall, research-grade outputs that help organisations reduce admin burden, use practical AI and automation sensibly, and apply AI governance without needing a technical team.

## Current status

**Status:** scaffold / research standard setup.

This project is not yet a finished research paper. The first phase is to define the method, evidence register, limitations, templates, and review discipline before publishing recommendations.

## Core research question

How can non-technical organisations use practical AI and automation to reduce admin burden while preserving human judgement, accountability, and operational safety?

## Focus areas

1. **Reducing admin burden** — repeat work, rekeying, inbox drag, manual follow-up, handoff friction, duplicated reporting, and hidden process debt.
2. **Small-business automation patterns** — low-risk, high-usefulness automation patterns for owner-led and lean teams.
3. **AI governance for non-technical teams** — practical rules for when AI can draft, summarise, classify, or assist, and when human review must remain explicit.

## What this project is

- A public evidence-to-action research pack.
- A set of practical templates, checklists, scorecards, and implementation notes.
- A cross-industry view of admin burden and practical AI adoption.
- A proof asset showing how AI can help produce useful, reviewable public outputs.

## What this project is not

- Not professional, legal, clinical, financial, regulatory, or operational advice.
- Not a medical or clinical recommendation system.
- Not a vendor ranking or sales funnel.
- Not a claim that AI should replace accountable human judgement.
- Not a finished research output yet.

## Planned outputs

- `research-paper.md` — cross-industry research paper.
- `methodology.md` — research method, evidence rules, and AI-assisted workflow.
- `evidence-register.csv` — source and claim register.
- `limitations.md` — scope limits, caveats, and safety boundaries.
- `templates/` — reusable tools for mapping admin burden, scoring automation opportunities, governance, and human review.
- `appendices/` — industry implementation translations built underneath the core research.

## Contribution and review posture

This is currently an authored research scaffold rather than an open contribution project. Issues, corrections, source suggestions, and practical implementation examples may be considered once the first evidence register and draft paper are in place.

Any material claim should be traceable to a source, method note, or clearly marked judgement call.

## Risk flags

Mark any that apply.

- [ ] Sensitive personal data.
- [ ] Clinical, legal, financial, regulatory, or safety-critical impact.
- [ ] Errors would be hard to detect.
- [ ] Errors would be hard to reverse.
- [ ] No clear workflow owner.
- [ ] No clear human review point.
- [ ] Source data is poor quality.
- [ ] Process is not stable enough to automate.
- [ ] Users do not trust the current process.

## Recommended intervention type

- [ ] Process cleanup only.
- [ ] Template / checklist.
- [ ] Simple no-code automation.
- [ ] AI-assisted summarisation.
- [ ] AI-assisted drafting.
- [ ] AI-assisted classification.
- [ ] Reporting / dashboard improvement.
- [ ] Needs specialist review before any automation.
